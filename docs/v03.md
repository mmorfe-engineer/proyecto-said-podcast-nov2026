# V03 · Reproducción y control editorial

La versión local se conforma sobre la EDL y el manifiesto de ensamblaje que produjeron los másteres V02 aprobados. Usa el máster limpio para conservar el balance de voces y el caché V02 para copiar el video de cada unidad retenida. El SRT se traslada por los desplazamientos de la EDL, respetando el texto aprobado de cada intervención.

## Requisitos locales

- Python 3.11 o posterior con Pillow y NumPy.
- FFmpeg y FFprobe con libx264, AAC, libass y filtros de escala.
- Fuentes configuradas en `config/episodio.json` y Lato para el subtitulado.
- El máster limpio V02, su SRT y el caché original de V02 con `edl.json`, `concat.txt` y los segmentos que referencia.
- Originales de video para los fotogramas de transición y configuración local de identidad. Copiar `config/identidad-v03.example.json` a `config/identidad-v03.local.json` y completar con los datos acreditados para la entrega privada.
- CairoSVG es opcional para un escudo SVG de procedencia confirmada. Pillow abre imágenes raster admitidas. Colocar el recurso institucional en `logo colegio/`. La ruta y el SHA-256 elegidos quedan en `work/v03/logo.json`.

```bash
python3 -m pip install Pillow numpy
python3 scripts/v03.py edl
python3 scripts/v03.py preview
python3 scripts/v03.py build
python3 scripts/v03.py audit
python3 scripts/v03.py gallery
```

`preview` genera cuatro muestras de movimiento. `build` genera las cortinas, el subtítulo y los dos másteres. `subtitled` permite retomar la segunda codificación si el máster limpio ya existe. `audit` decodifica ambos y comprueba cuadro por cuadro las piezas retenidas del máster limpio. `gallery` exporta arte editorial sin retratos ni nombres de estudiantes. Los archivos audiovisuales privados permanecen en `renders/v03/`.

## Cambios

- Apertura en dos momentos con tema, identificación institucional e integrantes. Cuatro capítulos con mancheta y un motivo de grafito diferente en cada caso.
- Cápsulas de clasificación, relaciones temáticas, evidencia textual y narrador. El epílogo existente se amplía con una pregunta editorial. La pregunta oral permanece en el video 8.
- Nueve unidades de conversación conservadas, procedentes de ocho archivos originales. Se mantiene el orden de participación, la imagen de las intervenciones y su subtitulado, con desplazamientos por gráfica añadida.
- Se retira solo `extra-espontaneo`, origen 5, 10.15–23.65, y se conserva la cortina de bloopers de V02.
- En `postura` se atenúan dos transitorios de la fuente. La gráfica añadida recibe motivos originales sintetizados. El agradecimiento termina con una resolución tonal y fundido.
- Identidad escrita del colegio en la entrega local. El recurso de escudo no estaba disponible en la carpeta designada.

## Recursos y derechos

| Recurso | Procedencia y uso |
|---|---|
| Grafito, máscaras y diagramas | Generación procedural mediante Pillow y NumPy. La galería pública se genera sin fotogramas de alumnos. |
| Música | Síntesis local del pipeline V02 y cierre tonal V03. Sin grabaciones ni pistas de terceros. |
| Tipografías | DejaVu y Lato mediante las instalaciones locales. Sus archivos no se distribuyen con el repositorio. |
| Grabaciones, nombres, subtítulos y hojas de contacto privadas | Uso local para la actividad. La publicación requiere autorización adecuada. |

| Cita literaria breve | Fragmento atribuido del capítulo XXXVIII para comentario crítico. Se conserva el enlace para cotejo. |
| Clasificación de violencias | Definiciones parafraseadas y atribuidas a ONU Mujeres. |
